# Инструкция по установке

## Шаг 1: Создание иконок

1. Откройте файл `create-icons.html` в браузере
2. Нажмите кнопку "Создать иконки"
3. Иконки будут автоматически скачаны в папку загрузок
4. Переместите файлы `icon16.png`, `icon48.png`, `icon128.png` в корневую папку расширения

## Шаг 2: Установка расширения

1. Откройте Chrome и перейдите по адресу: `chrome://extensions/`
2. Включите "Режим разработчика" (переключатель в правом верхнем углу)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку с расширением (`task-update_extantion`)

## Шаг 3: Использование

1. Откройте Google Sheets с вашими задачами
2. Нажмите на иконку расширения в панели инструментов Chrome
3. Заполните настройки:
   - **YouTrack Host**: `https://youtrack.wildberries.ru` (или ваш хост)
   - **YouTrack Token**: Ваш токен API
   - **Столбец задач**: Буква столбца (например, `A`)
   - **Столбец статусов**: Буква столбца (например, `B`)
   - **Диапазон строк**: Например, `2-10`
4. Нажмите "Сохранить настройки"
5. Нажмите "Получить статусы"
6. Просмотрите предпросмотр и нажмите "Применить" или "Отмена"

## Примечания

- Убедитесь, что Google Sheets полностью загружен перед использованием
- ID задач должны быть в формате `XXX-123` (например, `PROJ-456`)
- Расширение ищет статусы в полях `Stage3` или `Stage` из YouTrack API
