# Политика конфиденциальности — YT Status Tools

**Дата вступления в силу:** 29 января 2026 г.

## 1. Общие положения

Расширение YT Status Tools («Расширение») не собирает пользовательские данные для передачи разработчику или третьим лицам. Все данные хранятся только на устройстве пользователя.

## 2. Какие данные хранятся локально

Расширение использует хранилище браузера (`chrome.storage.local`) только для сохранения:

- **Настройки подключения:** адрес хоста YouTrack и токен доступа, которые вы вводите в настройках расширения;
- **Список задач:** текст из поля «Список задач», который вы вводите или вставляете;
- **Настройки таблицы:** выбранные колонки и их подписи;
- **Результаты запроса:** последние полученные поля задач (чтобы не терять данные при закрытии окна);
- **Позиция прокрутки** в интерфейсе расширения.

Эти данные **не покидают ваше устройство** и **не отправляются на серверы разработчика**.

## 3. Передача данных

- **Разработчику и третьим лицам:** данные не передаются. У расширения нет аналитики, рекламы и трекинга.
- **YouTrack:** запросы к API YouTrack выполняются **только** по адресу хоста, который вы сами указываете в настройках, и **только** при нажатии кнопки «Получить статусы». Данные уходят напрямую с вашего устройства на ваш инстанс YouTrack по вашему запросу.

## 4. Удаление данных

Все сохранённые данные можно удалить:

- **Очистить данные в расширении:** кнопка «Очистить» в интерфейсе очищает список задач и результаты; настройки (хост, токен, колонки) можно изменить или удалить вручную в настройках.
- **Удалить расширение:** при удалении расширения из браузера все его локальные данные удаляются браузером.

## 5. Изменения политики

Текущая версия политики опубликована в репозитории расширения. При существенных изменениях дата и текст обновляются в этом документе.

## 6. Контакты

По вопросам, связанным с конфиденциальностью и использованием расширения, можно обратиться через репозиторий проекта на GitHub (если указан в описании расширения в Chrome Web Store).
