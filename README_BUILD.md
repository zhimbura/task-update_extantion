# Инструкция по сборке расширения

## Установка зависимостей

```bash
npm install
```

## Сборка расширения

```bash
npm run build
```

После сборки все файлы будут в папке `dist/`. Используйте эту папку для загрузки расширения в Chrome.

## Разработка с автопересборкой

```bash
npm run dev
```

## Структура после сборки

```
dist/
  ├── manifest.json
  ├── popup.html
  ├── popup.js
  ├── content.js
  ├── sheets-api.js
  ├── styles.css
  └── *.png (иконки)
```

## Установка расширения

1. Откройте Chrome и перейдите в `chrome://extensions/`
2. Включите "Режим разработчика"
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку `dist/`

## Примечания

- Расширение использует Google Sheets API v4 через OAuth авторизацию
- При первом использовании потребуется авторизация через Google аккаунт
- Требуется разрешение `identity` для работы с OAuth
