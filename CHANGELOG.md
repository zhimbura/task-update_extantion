# Changelog

## [1.1.0] — 2026-01-29

### Добавлено
- **Колонки таблицы** — можно включать/отключать чекбоксом (скрывать без удаления), состояние сохраняется.
- **Поле Project** — отображается название проекта из API (`project(name,shortName)`).
- **Даты** — формат «25 февр. 2026 г. 15:00» (дата + время, локаль ru-RU).
- **Логи** — полный response API в JSON; что получено и как распарсено по каждому полю; краткие строки «ответ получен», «распарсено полей».
- **Горизонтальный скролл** таблицы при большом числе колонок.

### Исправлено
- **Stage, Priority, Subproduct, CallRequired** — значения теперь приходят и отображаются. Запрос к API изменён на `customFields(name,value(name))` (без второго `value`), иначе сервер возвращал только `$type`.
- **core_deadline и другие даты** — корректный разбор и вывод (число → форматированная дата).
- **Пустые значения** — null/undefined → «—», пустой массив → «empty»; без хардкода имён полей, определение по типу значения.

### Изменено
- Нет хардкода имён полей (AnalysisTarget, Stage и т.д.) — колонки работают с теми именами, что приходят из API; тип значения определяется по структуре ответа.
- Подсказки в настройках колонок обновлены (id, summary, project, Stage, Priority, core_deadline и т.д.).
- Копирование таблицы и «Копировать статусы» учитывают только видимые (включённые) колонки.
