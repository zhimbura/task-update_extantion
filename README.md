# YouTrack Task Status Updater - Chrome Extension

Chrome расширение для автоматического обновления статусов задач из YouTrack API в Google Sheets.

## Возможности

- Сохранение настроек (YouTrack Host и Token)
- Указание столбцов для задач и статусов
- Выбор диапазона строк для обработки
- Получение статусов из YouTrack API
- Предпросмотр изменений перед применением
- Отмена изменений (возврат к исходным значениям)

## Установка

1. Откройте Chrome и перейдите в `chrome://extensions/`
2. Включите "Режим разработчика" (Developer mode)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку с расширением

## Использование

1. Откройте Google Sheets с вашими задачами
2. Нажмите на иконку расширения в панели инструментов Chrome
3. Заполните настройки:
   - **YouTrack Host**: URL вашего YouTrack сервера (например, `https://youtrack.wildberries.ru`)
   - **YouTrack Token**: Токен для доступа к API
   - **Столбец задач**: Буква столбца, где находятся ID задач (например, `A`)
   - **Столбец статусов**: Буква столбца, куда записывать статусы (например, `B`)
   - **Диапазон строк**: Диапазон строк для обработки (например, `2-10`)
4. Нажмите "Сохранить настройки"
5. Нажмите "Получить статусы" - расширение загрузит статусы из YouTrack API
6. Просмотрите предпросмотр изменений
7. Нажмите "Применить" для сохранения изменений или "Отмена" для отмены

## Формат ID задач

Расширение ищет ID задач в формате `XXX-123` (например, `PROJ-456`). ID задачи может быть частью текста в ячейке.

## Статусы

Расширение ищет статусы в следующих полях YouTrack API:
1. Сначала ищет в поле `Stage3`
2. Если не найдено, ищет в поле `Stage`
3. Если ничего не найдено, устанавливает статус `Unknown`

## Требования

- Google Chrome или другой браузер на базе Chromium
- Доступ к Google Sheets
- YouTrack API токен с правами на чтение задач

## Разработка

### Структура проекта

- `manifest.json` - конфигурация расширения
- `popup.html` - интерфейс настроек
- `popup.js` - логика работы с настройками
- `content.js` - скрипт для работы с Google Sheets и API
- `styles.css` - стили интерфейса

### Иконки

Для работы расширения необходимы иконки:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

Для создания иконок:
1. Откройте файл `create-icons.html` в браузере
2. Нажмите кнопку "Создать иконки"
3. Иконки будут автоматически скачаны
4. Переместите их в корневую папку расширения

Или создайте иконки вручную в любом графическом редакторе.
