# Скриншоты для Chrome Web Store

Страница для **скачивания** скриншотов расширения **YT Status Tools** в размере **1280×800 px** (рекомендованный размер для Chrome Web Store). Ручные скриншоты делать не нужно — изображения сохраняются кнопками.

## Как скачать скриншоты

1. Откройте в браузере файл **`screenshot-page.html`** (двойной клик или «Open with» Chrome).
2. Выберите сцену: **Главный экран**, **Настройки** или **Результаты**.
3. Нажмите:
   - **«Скачать текущий (PNG)»** — сохранится один файл выбранной сцены;
   - **«Скачать все 3 скриншота»** — по очереди сохранятся три PNG: главный экран, настройки, результаты.

Файлы появятся в папке «Загрузки» с именами вида `yt-status-tools-main.png`, `yt-status-tools-settings.png`, `yt-status-tools-results.png`. Сохраните их в эту папку (`store-screenshots/`) и закоммитьте — тогда при создании релиза по тегу они автоматически попадут в артефакты релиза вместе с zip.

## Требования Chrome Web Store

- **Размер:** 1280×800 (рекомендуется) или минимум 640×400.
- **Формат:** PNG или JPEG.
- **Количество:** от 1 до 5 скриншотов.

Страница использует [html2canvas](https://html2canvas.hertzen.com/) с CDN для экспорта в PNG. Работает офлайн после первой загрузки (при наличии кэша).
