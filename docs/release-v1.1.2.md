## [1.1.2] — 2026-02-11

### Добавлено
- **Ошибка парсинга** — если в строке не распознан ID задачи (формат `PROJECT-123`), в таблице показывается строка с текстом «ошибка парсинга» (красным). При копировании столбца или таблицы для таких строк в буфер попадает «ошибка парсинга задачи».
- **Парсинг** — поддержка разных тире (обычный `-`, en-dash, em-dash, минус U+2212), чтобы копипаст из документов/мессенджеров не терял задачи.
- **Несколько ID в одной строке** — если в строке несколько идентификаторов (например `PVZMobile-1 PVZMobile-2`), все распознаются и добавляются в список.
- **Логи** — после парсинга выводится «Распознано задач: N: id1, id2, …»; при наличии строк без ID — «непустых строк без ID: N».

### Изменено
- **Порядок и количество** — дубликаты не удаляются: порядок строк и их число в таблице строго соответствуют входному полю (одна строка ввода = одна строка в таблице; один и тот же ID может встречаться несколько раз).
- Убрана кнопка **«Копировать статусы»** — копирование только через кнопку 📋 в заголовке нужного столбца или «Копировать таблицу».
